# Stratify

Website assets for **Stratify N.V.** — *Purpose. Clarity. Progress.*

| Folder | Contents |
|---|---|
| `content/` | `copy.md` — all website copy (hero, bio, approach, services, contact, SEO) |
| `brand/` | Logos, favicon, color/type tokens (`tokens.css`, `tokens.json`), `BRAND.md` guide |
| `site/` | One-page static site starter using the copy and brand kit |

## Preview

From the repo root (the site references `../brand/`):

```sh
python3 -m http.server 8000
# open http://localhost:8000/site/
```
