# Stratify Brand Kit

**Tagline:** Purpose. Clarity. Progress.

## Idea

*Strata* — layers that build on each other. The mark is three stacked bars that
step upward: governance, processes, and people forming a stable base, rising
toward progress (the gold top layer).

## Logo files

| File | Use |
|---|---|
| `logo.svg` | Primary logo on light backgrounds |
| `logo-reversed.svg` | Logo on navy / dark backgrounds |
| `logo-mark.svg` | Mark only — avatars, small spaces |
| `favicon.svg` | Browser tab / app icon |

Keep clear space around the logo equal to the height of one bar. Don't recolor,
stretch, or add effects. The wordmark uses live text in Fraunces; before print
or external use, outline the text in a vector editor (Figma/Illustrator).

## Colors

| Token | Hex | Use |
|---|---|---|
| Ink | `#12233a` | Primary text, dark sections |
| Ink 2 | `#2f4560` | Secondary surfaces, middle bar |
| Gold | `#c39a4e` | Accent, CTAs on dark, top bar |
| Gold deep | `#9a7432` | Accent text/links on light backgrounds |
| Paper | `#f7f4ee` | Page background |
| Stone | `#e6e0d4` | Dividers, cards |
| Slate | `#5a6676` | Secondary text |

Use gold sparingly — one accent per view.

## Typography

- **Display:** Fraunces (serif) — headlines, quotes. Weight 400–600.
- **Body:** Manrope (sans) — text, UI, labels. Weight 400–700.

Both are free on Google Fonts. Tokens live in `tokens.css` / `tokens.json`.

## Voice

Calm, precise, confident. Plain language over jargon; name the standard
(ISO 27001) but lead with the outcome (secure, resilient, compliant).
Favor short sentences and active verbs: *strengthen, clarify, build, guide*.
